Track B ☁ Cloud ⚙ DevOps

Cloud & DevOps Bootcamp

From AWS fundamentals to Kubernetes in production — a hands-on 3-week intensive.

Overview

Track B gives 2nd and 3rd year engineering students a structured path through cloud infrastructure and DevOps tooling — the skills most commonly tested in placements at product companies. Students work on live AWS accounts from Day 1, not sandboxes.

The program runs in-person at your campus over 3 weeks (sessions scheduled around your timetable), with optional evening lab hours for hands-on practice. Batch sizes up to 60. A post-training assessment benchmarks each student against the question bank.

What students will be able to do

  • ✓Deploy a full application on AWS EC2 with auto-scaling
  • ✓Build and run Docker containers, write production-quality Dockerfiles
  • ✓Set up a CI/CD pipeline with GitHub Actions from scratch
  • ✓Manage cloud infrastructure with Terraform
  • ✓Debug and monitor applications with CloudWatch & logs

Syllabus

Module 1: AWS Fundamentals (6 hrs)
  • IAM & Security — users, roles, policies
  • EC2 & Auto Scaling groups
  • S3 & CloudFront — storage and CDN
  • VPC & Networking basics
Module 2: Containers & Docker (4 hrs)
  • Docker concepts and architecture
  • Writing Dockerfiles and multi-stage builds
  • docker-compose for local development
  • Image registries — ECR, Docker Hub
Module 3: CI/CD Pipelines (6 hrs)
  • GitHub Actions — workflows, triggers, secrets
  • Automated testing in the pipeline
  • Deployment automation to EC2 / ECS
  • Branch strategies and environment promotion
Module 4: Kubernetes Basics (4 hrs)
  • Pods, Deployments and ReplicaSets
  • Services & Ingress controllers
  • ConfigMaps & Secrets management
  • kubectl essentials and debugging
Module 5: Terraform & Infrastructure as Code (4 hrs)
  • HCL syntax — providers, resources, variables
  • Resource blocks and data sources
  • State management and remote backends
  • Reusable Terraform modules

Features

Built for campus cybersecurity training

Every feature is designed to work with batches of 30–120 students in a college lab setting.

🚩

Flag-based scoring

Students submit captured flags to earn points. Each challenge has a unique flag preventing answer-sharing. Partial scoring supported for multi-stage challenges.

👥

Team & individual mode

Run as individual competition or team-based. Teams of 2–5, auto-balanced by trainer. Leaderboard reflects both individual and team standings simultaneously.

🖥️

Real lab environments

Challenges run on actual Linux VMs and network topologies — not browser-based simulations. Students use standard tools: nmap, Burp Suite, Wireshark, netcat.

📚

Custom challenge library

Trainers can build custom challenges mapped to the batch's syllabus. Challenges are versioned, reusable across batches, and difficulty-tagged.

📊

Live leaderboard

Real-time scoring updates visible to all students. Leaderboard can be frozen at the trainer's discretion during the final phase for suspense. Exportable after session.

⚙️

Trainer dashboard

Monitor solve rates per challenge, release hints with timing control, see which students are stuck and intervene. Full session analytics available post-debrief.

How It Works

How a CTF session runs

From setup to debrief — a typical campus CTF session runs in 3–4 hours.

Step 1

Trainer creates the challenge set

Trainer selects from the challenge library or builds custom challenges. Sets difficulty distribution, time limit, hint release schedule, and team configuration.

Step 2

Students join the batch

Students access the platform via a session code. Lab environments spin up per student or team. Each student gets their own isolated flag instance.

Step 3

Live solving with hints

Students solve challenges in real time. Trainer monitors progress and releases hints at set intervals or on demand. Leaderboard updates live throughout the session.

Step 4

Leaderboard reveal + debrief

Final leaderboard is revealed. Trainer walks through each challenge's intended solution. Solve-rate analytics exported for placement records and batch assessment reports.

Challenge Categories

What students actually solve

Challenges span six categories aligned to real-world security roles and interview assessments at product companies.

WEB

Web Exploitation

SQL injection, XSS, CSRF, authentication bypass, IDOR, API vulnerabilities. Challenges use real web apps with intentional flaws.

BIN

Binary / Reverse Engineering

ELF binary analysis, buffer overflows, disassembly with Ghidra, format string vulnerabilities. Progressive difficulty from beginner to advanced.

NET

Network Forensics

PCAP analysis with Wireshark, protocol dissection, traffic reconstruction, man-in-the-middle detection, firewall rule analysis.

CRYP

Cryptography

Classical ciphers, RSA attacks, hash cracking, encoding/decoding, XOR challenges, certificate analysis. Calibrated to Anna University cryptography syllabus.

OSINT

OSINT

Open source intelligence challenges: social media investigation, domain research, metadata extraction, geolocation from images. No special tools required.

MISC

Miscellaneous

Steganography, file carving, log analysis, trivia, and puzzle challenges. Good warm-up challenges for batches new to CTF format.
